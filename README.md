# Simple Interest Calculator

## Description

The Simple Interest Calculator is a basic calculator that calculates the simple interest on a principal amount based on the interest rate and time period.

## Formula

**Simple Interest = (Principal × Rate × Time) / 100**

Where:

* **Principal (P)** = Initial amount of money
* **Rate (R)** = Annual interest rate in percentage
* **Time (T)** = Time period in years

## Example

Suppose:

* Principal = 1000
* Rate = 5%
* Time = 2 years

Calculation:

**Simple Interest = (1000 × 5 × 2) / 100**

**Simple Interest = 100**

Therefore, the simple interest is **100**.

## Features

* Calculate simple interest easily
* Accepts principal amount as input
* Accepts interest rate as input
* Accepts time period as input
* Displays the calculated simple interest

## How to Use

1. Enter the principal amount.
2. Enter the annual interest rate.
3. Enter the time period in years.
4. Calculate the simple interest.
5. The calculated interest will be displayed.
